About mkv-transcode

    

      
mkv-transcode converts MakeMKV rips into small AV1 or HEVC Matroska
      files. It watches an incoming folder, names each file from a
      local IMDb index, and re-encodes the video with ffmpeg. A typical film
      drops to one quarter of the original size.

      
This page shows the watcher state, the job in progress, the queue, and
      the job history. It reads the state file, the job logs, and the JSON
      reports. It changes nothing, except uploaded files when you turn uploads
      on.
